**Fit-Bud** is a web-based platform dedicated to helping individuals achieve their health goals. This repository contains the frontend source code for the Fit-Bud landing page, featuring sections for personalized training bookings, merchandise shopping, and customer testimonials.

## 🚀 Features

* **Responsive Navigation:** Easy access to Home, About, Shop, and Booking sections.
* **Booking Interface:** A detailed HTML form designed to capture user metrics (Height, Weight) and fitness goals for personalized plan creation.
* **Merchandise Showcase:** A grid-based layout displaying fitness gear and apparel.
* **Testimonials Section:** A dedicated area for customer reviews and social proof.
* **Brand Information:** An "About Us" section detailing the company's mission of virtual training and community support.
